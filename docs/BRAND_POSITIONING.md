# SoraFiles Brand Positioning

## Product

SoraFiles

## Builder

Sora Labs

## Tagline

A privacy-first file app that runs locally in your browser.

## Description

SoraFiles is a privacy-first web app for working with PDFs and images directly in your browser. Supported file processing happens locally on your device.

## Brand rule

SoraFiles is one application. Individual file operations are workflows and features inside it, not unrelated products.

## SEO rule

Workflow pages retain explicit search intent. Compress PDF remains Compress PDF, Merge PDF remains Merge PDF, and equivalent workflow names remain intact in every locale.

## Do not lead with

- A tool count
- A collection of tools
- A converter directory

Labels such as Tools, All Tools, Related Tools, and individual workflow names remain valid when they help people navigate the application.

## Architecture

Supported processing is full-local and browser-side. Use the precise wording: “Supported file processing happens locally on your device.” Do not claim zero network activity; analytics, the contact form, static assets, and first-party popularity events are separately disclosed.

## Monetization

Ad-free and build-first. Do not add ad-network code or placeholders.

## Analytics

No Google Analytics or Google Tag Manager. Preserve Ahrefs Web Analytics only while it remains current and disclosed. Never expose filenames, file contents, OCR text, signatures, passwords, metadata values, or generated output to analytics.

## Open source

AGPL-3.0-only. The repository is the source for one SoraFiles application.

## Portable workspace

All durable SoraFiles context belongs on the mounted USB volume `Web Apps`, inside its `SoraFiles` folder. Detect the volume by label on each computer; do not rely on a fixed Windows or macOS path.
