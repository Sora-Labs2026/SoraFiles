# SoraFiles Privacy Policy

Last reviewed: August 23, 2026.

This repository policy mirrors the current public policy at [sorafiles.com/privacy](https://sorafiles.com/privacy).

## 1. Files are processed locally

Files selected in supported tools are read into browser memory and processed on the user's device. They are not uploaded to SoraFiles or a conversion service. Generated results are separate downloads; original files are never modified.

## 2. No accounts

SoraFiles requires no sign-up and stores no user profiles for its file tools.

## 3. Local preferences

Language and theme choices may be stored only in the user's browser local storage.

## 4. Advertising

Clearly labeled Adsterra display and native banners may appear at separated boundaries on home and tool pages and make ordinary network requests while the user is online. They receive no file names, file contents, generated outputs, or processing data, and tools never wait for them.

## 5. Analytics

SoraFiles uses Google Analytics and Ahrefs Web Analytics to understand page visits and improve the website. Analytics may process page activity, device information, and approximate location, but never receives file names, file contents, generated downloads, or local processing data.

## 6. Offline use

After the first load, the app shell and core tools may be cached by a service worker. User files are never written to that cache.

## 7. Contact form

The contact form is a separate, voluntary network submission. A user's name, email address, subject, message, and optional attachment are sent through FormSubmit for delivery to Sora Labs. Do not attach confidential files.

## 8. Public source and contributions

The application source is public at [github.com/Sora-Labs2026/SoraFiles](https://github.com/Sora-Labs2026/SoraFiles) under AGPL-3.0-only. Local processing does not send selected files to GitHub. Issues, discussions, pull requests, comments, and attachments posted on GitHub are public; do not post confidential files or personal data.

Privacy questions can be sent to **contact@sorafiles.com**.
