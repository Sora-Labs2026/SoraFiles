# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or privacy leak.

Email **contact@sorafiles.com** with:

- a concise description of the issue;
- the affected route, browser, and version;
- safe reproduction steps;
- the potential privacy or security impact; and
- any suggested mitigation.

Do not include real confidential documents, authentication secrets, or other people’s personal data. Use a minimal synthetic fixture when a file is necessary to explain the issue.

Include the affected commit or live route, browser and operating system, impact, safe reproduction steps, and whether the issue is already publicly known. Please avoid public disclosure until maintainers have had a reasonable opportunity to investigate.

Sora Labs will triage useful reports as capacity allows and may ask for clarification or a synthetic reproduction. This early-stage project does not currently offer a bug bounty or guaranteed response or resolution time.

## Supported version

Security fixes target the current default branch and the currently deployed website. Older snapshots, forks, and unofficial deployments may not receive fixes.

| Version | Supported |
| --- | --- |
| Current `main` and current deployment | Yes |
| Older commits, forks, and unofficial deployments | No guarantee |
