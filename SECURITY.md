# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or privacy leak.

Email **soralabs2026@gmail.com** with:

- a concise description of the issue;
- the affected route, browser, and version;
- safe reproduction steps;
- the potential privacy or security impact; and
- any suggested mitigation.

Do not include real confidential documents, authentication secrets, or other people’s personal data. Use a minimal synthetic fixture when a file is necessary to explain the issue.

Sora Labs will acknowledge useful reports as capacity allows. This early-stage project does not currently offer a bug bounty or guaranteed response time.

## Supported version

Security fixes target the current default branch. Older snapshots and forks may not receive fixes.
